Sistema web para gerenciamento de clientes, desenvolvido com C# e ASP.NET MVC 5, utilizando NHibernate para persistência de dados e SQL Server como banco de dados.

Objetivo:

Este projeto tem como objetivo desenvolver uma aplicação de gerenciamento de clientes, aplicando conceitos de desenvolvimento web com ASP.NET MVC, arquitetura em camadas, ORM e operações CRUD.

Além de construir uma aplicação funcional, o projeto busca consolidar conhecimentos e boas práticas de desenvolvimento com C# e .NET Framework.

Tecnologias utilizadas:
- C#
- ASP.NET MVC 5
- .NET Framework 4.8
- NHibernate
- SQL Server
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git e GitHub

Funcionalidades:

- Listagem de clientes
- Cadastro de clientes
- Visualização dos detalhes de um cliente
- Edição de clientes
- Exclusão de clientes
- Validação de formulários
- Integração com banco de dados SQL Server
- Estrutura e conceitos

Durante o desenvolvimento serão aplicados conceitos como:

- Arquitetura MVC (Model-View-Controller)
- Separação de responsabilidades
- Programação orientada a objetos
- Interfaces e serviços
- Mapeamento objeto-relacional (ORM)
- Operações CRUD
- Validação de dados
